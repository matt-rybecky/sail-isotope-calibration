# Published Dataset — SAIL water vapor stable isotopes (1-minute)

**Purpose:** the archival, DOI-ready 1-minute water vapor stable isotope
record (dD, d18O, d-excess) with per-point uncertainties and full coverage
accounting; the exact stream the transfer-entropy analysis was run on.
**Status:** complete
**Created:** 2026-07 — **Updated:** 2026-07

## Contents
- `sail_water_vapor_isotopes_1min.csv` — the dataset. A complete
  276,154-minute grid over the full measurement span (2022-11-21 20:12 to
  2023-06-01 14:45, **not** winter-truncated); 261,757 measured minutes.
  Columns: `time`, `H2O_ppm`, `dD_vsmow_permil`, `d18O_vsmow_permil`,
  `d_excess_vsmow_permil`, `is_interpolated`, `dD_uncertainty_permil`,
  `d18O_uncertainty_permil`, `d_excess_uncertainty_permil` (propagated,
  rho=0), `d_excess_uncertainty_direct_permil`, `unc_extrapolated`.
- `dataset_metadata.md` — **read this**: full provenance (source SHA-256),
  column dictionary, the humidity-dependent uncertainty model, and the
  TE-match verification table.
- `coverage_report.{md,csv}` — every gap's start/end/length with a
  calibration-vs-outage label, plus the uptime summary.

## Provenance / Notes
- **Generated by** `../../code/pub_published_dataset.py` (with
  `pub_isotope_uncertainty.py` and `pub_te_match.py`). Regenerate:
  `python3 pub_published_dataset.py` from `WRITING/Manuscript/code/`.
- **Source:** the pipeline's 1-minute time-rolling VSMOW-SLAP output
  `PROJECTS/SAIL/isotope-analysis-pipeline/.../atmospheric_isotopes_vsmow_final_cleaned.csv`
  (1-minute cadence; each value a uniform 5-minute rolling mean of the
  native ~10 s Los Gatos analyzer stream). The native stream
  `..._corrected_full.csv` (376 MB) is REFERENCED not copied; it supplies
  the per-window sample counts for the uncertainty reduction.
- **Verified identical to the analyzed data.** Aggregating this file with
  the analysis kernel (Gaussian sigma = 0.25 x interval, +/-4 sigma; linear
  fill of gaps <= 3 h) reproduces `MODELS/TE_V1.0.0/data/final_1hr.csv`
  and `final_6hr.csv` isotope columns to ~1e-12 (all checks PASS; table in
  `dataset_metadata.md`). This corrects the earlier `../README.md` step 5
  note: `final_cleaned` does NOT predate the spike removal and IS the
  analyzed stream (the 2022-12-12 18:55-19:22 malfunction window is already
  interpolated in it). The old "r = 0.997, not identical" came from
  comparing the 1-minute series directly against the 1-hour series without
  aggregating first.
- **Cleaning (measured-only).** Calibration-run periods are absent
  (instrument on standards) and appear as gaps, labeled by date match to
  `../calibration/sliding_window_standards_data.csv`. The one malfunction
  window (28 min) is interpolated in place and flagged `is_interpolated`;
  every other outage is an explicit NaN gap.
- **Uncertainty model of record:** `../calibration/uncertainty_summary.json`
  (13 standards runs, 28,456 points; `sigma(H2O) = a*exp(-b*H2O/1000)+c`);
  lag-1 autocorrelation for the averaging reduction:
  `../calibration/autocorr_summary.json`. Values are hardcoded with
  provenance in `pub_isotope_uncertainty.py`.
- **Manuscript role:** this is the isotope data product to deposit and cite
  in the Open Research Statement (checklist B3).
